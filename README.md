Titulo - free music

resumo - um aplicativo para pesquisar e baixar musicas gratuitas em formato de MP3 onde o usuário digita o nome de alguma musica e faz o download

funcionalidades - campo de busca de musica por nome e exibição de resultados com titulo e duração
- botão para baixar a musica
- histórico das ultimas musicas pesquisadas pelo usuário
